# Reference Screenshots

Screenshots from reference finance apps used in [`docs/principles/ui-reference.md`](../../principles/ui-reference.md) to provide visual anchors alongside text descriptions.

## How to Add Screenshots

1. Visit the app's public marketing page or App Store listing
2. Take a screenshot of the relevant screen
3. Crop to the relevant area (no browser chrome)
4. Save as PNG at reasonable resolution (max ~1200px wide)
5. Use the exact filename listed below
