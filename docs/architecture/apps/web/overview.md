## Routing

We use TanStack Router with file-based routing. Routes are defined in `src/routes/`:

```
routes/
├── __root.tsx         # Root layout
├── index.tsx          # / (Dashboard)
├── transactions.tsx   # /transactions
├── cash-flow.tsx      # /cash-flow
├── assets.tsx         # /assets
├── goals.tsx          # /goals
└── settings.tsx       # /settings
```

### Creating a New Route

1. Create a file in `src/routes/`:

```tsx
// src/routes/reports.tsx
import { createFileRoute } from '@tanstack/react-router';

export const Route = createFileRoute('/reports')({
  component: Reports,
});

function Reports() {
  return <div>Reports page</div>;
}
```

2. The route is automatically registered by TanStack Router.

## State Management

### Zustand Stores

For UI state that persists across routes:

```tsx
// src/stores/preferences-store.ts
import { create } from 'zustand';

interface PreferencesState {
  balanceVisible: boolean;
  toggleBalanceVisibility: () => void;
}

export const usePreferencesStore = create<PreferencesState>((set) => ({
  balanceVisible: true,
  toggleBalanceVisibility: () => set((state) => ({ balanceVisible: !state.balanceVisible })),
}));
```

### URL State with nuqs

For filter state that should be shareable via URL:

```tsx
// src/hooks/use-transaction-filters.ts
import { parseAsString, parseAsArrayOf, useQueryStates } from 'nuqs';

export function useTransactionFilters() {
  const [filters, setFilters] = useQueryStates({
    search: parseAsString.withDefault(''),
    categories: parseAsArrayOf(parseAsString).withDefault([]),
    dateFrom: parseAsString,
    dateTo: parseAsString,
  });

  return { filters, setFilters };
}
```

## Components

### shadcn/ui Components

Located in `src/components/ui/`. These are copied from shadcn/ui and can be customized.

To add a new component:

```bash
npx shadcn@latest add dialog
```

### Custom Components

Follow this pattern:

```tsx
// src/components/dashboard/monthly-summary.tsx
import { Card, CardContent, CardHeader, CardTitle } from '@/components/ui/card';
import { formatYen } from '@repo/shared';

interface MonthlySummaryProps {
  income: number;
  expenses: number;
  balanceVisible: boolean;
}

export function MonthlySummary({ income, expenses, balanceVisible }: MonthlySummaryProps) {
  return (
    <Card>
      <CardHeader>
        <CardTitle>Monthly Summary</CardTitle>
      </CardHeader>
      <CardContent>
        <p>{balanceVisible ? formatYen(income) : '¥•••••'}</p>
      </CardContent>
    </Card>
  );
}
```

## Data Fetching

All routes use generated react-query hooks from `@repo/api-client` (generated by Orval from the OpenAPI spec).

```tsx
import { useGetDashboard } from '@repo/api-client';

function Dashboard() {
  const { data, isLoading, error } = useGetDashboard();

  if (isLoading) return <Loader2 className="animate-spin" />;
  if (error) return <p>データの読み込みに失敗しました</p>;

  const dashboard = data?.data;
  return <NetWorthHero current={dashboard?.net_worth?.current ?? 0} />;
}
```

API response types use snake_case (matching Go JSON tags). Route components map API types to component prop shapes where needed.

## Charts

We use Recharts for data visualization:

```tsx
import { LineChart, Line, XAxis, YAxis, Tooltip, ResponsiveContainer } from 'recharts';

function AssetTrendChart({ data }: { data: DataPoint[] }) {
  return (
    <ResponsiveContainer width="100%" height={300}>
      <LineChart data={data}>
        <XAxis dataKey="date" />
        <YAxis tickFormatter={(v) => `¥${(v / 10000).toFixed(0)}万`} />
        <Tooltip formatter={(v) => formatYen(v as number)} />
        <Line type="monotone" dataKey="total" stroke="hsl(var(--primary))" />
      </LineChart>
    </ResponsiveContainer>
  );
}
```

## Common Patterns

### Balance Visibility

Always check `balanceVisible` before showing financial values:

```tsx
const { balanceVisible } = usePreferencesStore();

<span>{balanceVisible ? formatYen(amount) : '¥•••••'}</span>;
```

### Yen Formatting

Use utilities from `@repo/shared`:

```tsx
import { formatYen, formatYenSigned, formatYenCompact } from '@repo/shared';

formatYen(1234567); // "¥1,234,567"
formatYenSigned(-1234); // "-¥1,234"
formatYenCompact(190000); // "¥19万"
```
